# Marketing Workflows

These are orchestration sequences, not rigid chains. Skip steps when reliable context already exists.

## Organic social post

1. Confirm objective, audience, platform, and offer/context from available information.
2. Load product-marketing if positioning is not already clear.
3. Load content-strategy if the topic/role of the post still needs to be chosen.
4. Load social for platform-native execution and hooks.
5. Load copywriting-frameworks only when a framework improves the message.
6. Draft several distinct angles when the creative choice is important; select the strongest rather than presenting near-duplicates.
7. Run anti-ai-quality.

## Social campaign / content calendar

1. product-marketing
2. customer-research when audience evidence is insufficient
3. marketing-plan for campaign objective and sequencing when campaign-level planning is requested
4. content-strategy for pillars and topic roles
5. social for channel execution and calendar structure
6. brand-voice-guidelines when voice must be defined or enforced
7. anti-ai-quality on representative/public copy

Each post should have a job in the campaign. Avoid a calendar that is merely a random rotation of services.

## Paid social / Meta-style advertising

1. product-marketing
2. customer-research or verified audience context
3. marketing-psychology
4. ads for campaign strategy, objective, audience structure, measurement, and optimization
5. ad-creative for angle, hook, creative concept, and meaningful variants
6. ad-copy for paid-social copy variants
7. copychief for final conversion critique
8. anti-ai-quality

Do not invent urgency, testimonials, or performance claims to make the ad stronger.

## Landing page / service page

1. product-marketing
2. customer-research
3. marketing-psychology when persuasion/friction diagnosis matters
4. copywriting-frameworks for structural options
5. copywriting for page copy
6. copychief for strong conversion pages
7. copy-editing for clarity/polish as needed
8. anti-ai-quality

## Offer development

1. product-marketing
2. customer-research
3. marketing-psychology
4. offers
5. copywriting
6. copychief
7. anti-ai-quality

## Launch

1. product-marketing
2. customer-research
3. marketing-plan
4. launch
5. offers when packaging is part of launch design
6. content-strategy/social/ads according to channels
7. relevant copy modules
8. final quality gates

## Existing-copy review

If the user supplies finished copy and asks for improvement rather than a new strategy:

- use copy-editing for clarity and polish;
- use copychief for conversion-heavy copy;
- use brand-voice-guidelines if voice consistency is the issue;
- use anti-ai-quality before final delivery.

Do not rebuild the entire marketing strategy unless the supplied copy exposes a fundamental strategic problem.
